What this scene measures

This scene uses the shared renderer preparation interface, the apartment model and our original 7,628-triangle ÄPPLARYD. The additional models use the same original IKEA asset URLs as the editor’s qualified catalogue. It does not reproduce the editor UI. The worker and model remain loaded between runs. Material extraction, atlas generation and transfer tracing run again each time.

The preview keeps rendering during preparation. Adaptive scheduling caps batches at 512 samples and uses smaller batches with longer pauses when frame times rise. The ray count and lighting inputs stay fixed between kernels. Batch size changes GPU scheduling and readback frequency. Pauses can improve responsiveness but add time. Opening this scene never starts a bake. Hiding the page stops the current job after its pending GPU batch.

Streaming adds measured skylight and one bounce of sun and lamp light as ray batches finish. Unfinished areas retain direct lighting. The provisional light remains visible while the complete four-bounce result installs. Turn streaming off to compare preparation time and cache hashes. The preview has no reflection probes or bloom.
